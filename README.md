## How to install sburb.EXE

you will NEED the [Unoffical homestuck collection](https://github.com/GiovanH/unofficial-homestuck-collection).

1. Download the zip file from the release section.
   
3. put the zip file in the the "mods" folder in where ever you assets folder is.
   
   "../assetsfolder/mods/HERE"

   if you don't know where you assets folder is you can just click the "mods directory" link mod setting section in settings
   
5. you can either extract the contents into the same folder or leave it
   
6. open UHC and navigate to the Mod Settings section in settings
  
7. You will See (Hopefuly) SBURB.exe in the inactive section move it to the active section by draging it.
   1. IF you left the zip folder as is you might click [refresh mod list] a couple times and wait for a bit for it to show up.
  
8. then press [Reload Application] or just relaunc`h the program
  
9. You then can read it by going to the main page and scrolling to the new/not new "MS Paint Fan Adventures" section on the page.
   you can also just change the url to "/mspfa/SBURB.exe/1"
